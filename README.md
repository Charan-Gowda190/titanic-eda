# 🚢 Titanic Dataset – Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

The objective is to clean the data, explore passenger characteristics, analyze survival patterns, identify relationships between variables, and generate meaningful insights through data visualization.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- MatplotlibS
- Seaborn
- Jupyter Notebook

## 🔍 Data Analysis Performed

### 1. Data Inspection
- Loaded and inspected the Titanic dataset
- Examined dataset structure and data types
- Checked descriptive statistics
- Checked missing values
- Identified duplicate records

### 2. Data Cleaning
- Removed duplicate records
- Removed irrelevant columns
- Handled missing values
- Imputed missing Age values based on passenger class
- Handled missing Fare values
- Handled missing Embarked values
- Detected Fare outliers using the IQR method

### 3. Exploratory Data Analysis

The analysis explores:

- Passenger survival distribution
- Survival by passenger class
- Survival by gender
- Survival by age group
- Age distribution
- Fare distribution
- Relationships between numerical variables
- Correlation between important features

### 4. Data Visualization

The project uses:

- Histograms
- Distribution plots
- Count plots
- Bar charts
- Box plots
- Correlation heatmap

These visualizations help identify patterns and relationships within the Titanic dataset.

## 📊 Key Analysis Areas

Some of the main questions explored in this project include:

- How was survival distributed among passengers?
- How did passenger class relate to survival?
- How did gender relate to survival?
- How did age relate to survival?
- What patterns can be observed in passenger fares?
- What relationships exist between the numerical variables?
